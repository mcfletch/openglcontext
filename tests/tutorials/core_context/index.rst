OpenGLContext Core Tutorials
=============================

These tutorials cover the basics of using OpenGLContext as a library
for building software without "opening the hood". They are not
intended to teach low-level OpenGL principles. For that, see 
:doc:`shaders/index`.

OpenGLContext is a large engine, similar to a game engine in that it
provides rendering, physics, NPC support, and some (limited) special 
effects (fire, smoke). You can construct new games on top of it 
but it is a blank canvas on which to create your game or application,
not a pre-defined game environment from which to start modifications.

You will need to have 3D models to produce any non-trivial game,
so you'll either need to use Creative Commons (or similar) 
Licensed assets, or buy or build your own assets. You can use
Blender to generate glTF content that can be loaded in
OpenGLContext.
