Low Level and Legacy OpenGL
===========================

These tutorials/demos/scripts demonstrate effects that are
based on legacy features, or features of individual windowing
systems, and as such should not be used in OpenGLContext based
applications.

Their purpose is primarily to exercise those features for
PyOpenGL regression tests.

Individual tutorials might introduce a particular OpenGL 
extension, or a particular way of calling a particular entry 
point. As such they are only of interest if you are looking
to understand how that feature works.

You likely do **NOT** want to read this sequence all the way
through, as it is more of a grab bag of deprecated features
than something you would want to learn from.
