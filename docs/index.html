OpenGLContext A Learning Environment for PyOpenGL

Introduction

OpenGLContext is a testing and learning environment for PyOpenGL. It provides a generic scenegraph engine (based on VRML97's scenegraph model) as well as basic context creation and interaction support in multiple GUI environments. Recent work adds a modern OpenGL 3.3 core-profile renderer, a physically based rendering (PBR) pass, and a glTF 2.0 loader and viewer.

Features

  • Works on Multiple GUI Environments with Keyboard, Mouse and GUI events
    • GLFW (recommended for core-profile / PBR rendering)
    • GLUT
    • Pygame
    • wxPython
    • Qt (using the OpenGLContext_qt project)
  • Provides Basic Interactivity
    • 3D Flying Mode
    • Selection rendering based on unique-color buffers
    • Timer mechanisms and simple event handling
  • Geometry Types
    • Points (and Point-sprites)
    • Lines
    • Polygons
    • Trimmed NURBs
    • Extruded Shapes (with GLE)
    • Spheres, Cylinders, Cones
  • Textures (with Pillow), Materials, and physically based (PBR) materials
  • Rendering
    • Legacy fixed-function pipeline (compatibility profile)
    • Modern shader pipeline (OpenGL 3.3 core profile)
    • Image-based lighting and dynamic shadows
    • Shader scenegraph nodes
    • Particle effects — fire, smoke, sparks and explosions in one instanced draw
  • Spatial audio — sound placed in the scene on glTF's KHR_audio_emitter model, mixed in numpy
  • HUD & developer overlay — reticule, meters and messages over a live world, and a provider-fed overlay of everything a player should never see
  • Optimizations
    • Caching infrastructure
    • Frustum culling
    • CPU node-path matrix calculation (forward/backward transforms)
  • Loaders
    • glTF 2.0 / GLB loader and viewer
    • VRML97 loader (SimpleParse is a required dependency)
    • Wavefront OBJ loader
    • BSP (Quake III file loader/viewer, with the Twitch project)
See the documentation page for more details.
